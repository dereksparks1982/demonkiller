# Original Demon Killer audio preservation

The original `Audio/` directory in `1.zip` holds **62 source audio files**, plus Godot import sidecars. Audio was a major part of the older project's development. **Preserve the source files as supplied**, not just streaming conversions, and preserve the individual credits/doc records.

### Original source categories

- `Audio/music/`: Fistauffjustice title theme WAV; William Hector Ashbringer theme WAV; Little Town orchestral OGG and the MIDI source.
- `Audio/ambience/`: Bristol storm OGG, title loop OGG, Stardust Touch ambience WAV.
- `Audio/sfx/player/`: player footsteps, grunts, death-choice cues; alternate dirt/water/stone/grass footsteps from Little Robot Sound Factory and Fantozzi.
- `Audio/sfx/`: thunder, wraith, user interface lever effects.
- `Audio/animals/horses/`: horse gallop.
- Other original files: slime attack, collect coin, character grunts, whoosh, Victor Natas adventure music.

- `WILLIAM_HECTOR_ASHBRINGER_SOURCE_RECORD_v0_2_88.md`

Other original records retained in the curated source package include `docs/assets/`, `docs/licences/`, `docs/system_design/`, and the audio-focused `docs/changelogs/` and `docs/codex/` records.

The original notes credit Sudocolon, InvisibleFrequencies, Fantozzi, and Little Robot Sound Factory, among others. Preserve attribution exactly as the original project recorded it. The Ashbringer session record did not include documented commercial rights, and is preserved without editorial changes.

**Binary transfer status:** the 62 source audio files are present in the owner ZIP and the verified 4,719-file preservation package, but the raw bytes are not yet in this GitHub branch; this index is not a substitute for the binary upload. No audio has been wired into the current game by this historical recovery.
