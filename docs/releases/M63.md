# M63 | Persistent civilian displacement and settlement homecoming

- New `living.refugees` saved registry with one durable status and history per eligible noncombatant NPC.
- The existing monster-held territory flag triggers evacuation when a separate safe region exists.
- Refugee camps reserve distinct, traversable positions and route via real inter-region gates. Decisions never alter actual NPC coordinates without the existing cardinal pathfinder.
- Occupation of both areas strands civilians; no free rescue or teleportation. Dead refugees remain dead, with one recorded casualty; M23 succession still handles replacements separately.
- A liberated home area must stay under settler control for at least 90 consecutive simulated world minutes. The resident then walks home before the return event is committed.
- Real worker location continues affecting shop opening, workshops and commerce, without replacing current business ownership or generating gold or items.
- Guard and escort roles remain on defensive and commercial duties.
- Read-only `GET /api/v1/refugees`, strict save validation, idempotent old-world migration and eight registered regression tests.

## Verification and exclusions
Isolated M63 arrival/shelter/return simulation passed, plus JavaScript syntax checks. The complete Node regression suite and a live browser/server integration test have not yet been run. No original artwork, Lilith cinematic, MIDI, on-screen buttons or menu system were modified. No GPL RunUO code was copied.
