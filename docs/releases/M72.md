# M72 | Persistent world walking across the green atlas

**Date:** November 8, 2026  
**Game version:** 0.2.70  
**DK Server version:** 2.31.16

## Goal

The owner chose to continue the existing vision: an enormous flat **9,216 × 9,216 grass world** with 2D pixel art, no 3D terrain mesh, and complete manual terrain painting in DK Architect. M72 establishes a concrete player-facing movement test over those same server-owned coordinates and elevation records.

## Changes delivered

- `server/world-walker-m72.cjs` implements a **persistent single-surveyor** with global position, direction and step count stored in optional `world_grid.walker`. The world-grid validator accepts the optional record and the world validator strictly validates it. Old saves load without migrations or destroyed data.
- Any terrain tile can be sampled from the existing M71 sparse grass base and hand-painted cell/sector overrides. A bounded 25×25 viewport queries the server's actual materials and signed heights, including across Streaming Cell boundaries and the world's outer edges. This does not allocate 84 million tile entries.
- Commands `place` and `step` are independently validated, serialized on the server's single-writer save queue and durably written to the world save before acknowledging success. `place` is a deliberate architect surveyor test, and `step` is cardinal, one tile only.
- Terrain types sea, deepwater, river, lake, cliff, boulder and crevasse cannot be traversed. Elevation differences greater than one level block a step. Draft building plans are **not** physical barriers until foundations exist. The server rejects movement outside the atlas rather than wrapping/teleporting.
- A surveyor is protected from being submerged by subsequent impassable fine paint or broad cell paints. Large brushes skip the protected cell while still applying elsewhere, maintaining M70 behavior.
- Added `GET /api/v1/world/walk` and `POST /api/v1/world/walk` to the existing loopback-only DK Server. Placement requires `X-DK-World-Editor: place`; stepping requires `X-DK-World-Walk: step`. The server returns the new position and nearby terrain/elevations, not a browser-supplied claim.
- Added a simple `dk-world-explore-m72.html` game view: **original 32×32 human facing sprites**, hand-coded flat-color 32px pixel ground, WASD/arrows, right-mouse-held cardinal walking and left-click ground/height inspection. No new terrain art, third-party assets, 3D, isometric camera or smoothing.
- DK Architect's World Pixel Painter has a **WALK HERE** control, placing the surveyor at the hovered tile or viewport center. The main menu's persistent-world options can reopen the walking view to resume its saved location.
- Existing project README remains a concise player guide; detailed implementation and follow-on work stay in `docs/`.

## Regression contracts

`tests/world-walker-m72.cjs` adds ten focused Node tests: unstarted world and safe defaults; movement across 128-tile seams; water, cliff and height collisions; world boundaries; occupied-tile paint protection; the noncollision of unbuilt blueprints; diagonal rejection; bounded 25×25 terrain streaming; original sprite/browser controls; loopback header validation and world-save restart.

**Validated in this build:** JavaScript syntax and V8 isolated module tests using the actual updated terrain, atlas, grid and walker source with mocked Node require. Passed cell crossing, grass and painted water, painting grass to reopen passage, slope limits, protected cells, world validators and exported terrain.

**Not yet validated:** full Node regression suite, browser pointer accuracy in Firefox, HTTP integration from a running Linux checkout, high-frequency walking performance or mixed NPC/gameplay behavior. Do not describe these as passed.

## Honest limitation

This **surveyor is not the permanent Demon Killer character**. It is deliberately separate from old temple/courtyard character, combat, inventory and NPC state. The prototype makes the authored 9,216² terrain surveyable and continuously walkable, with real server collision and persistence, but does not yet run the old RPG's complete systems on the new map. No old architecture or generated settlements were reintroduced. A real playable-world migration needs a later coordinated slice.

## Next

After that build a lightweight cliff/shore transition renderer, river hydrology and Life is Feudal-style buildable terrain.
