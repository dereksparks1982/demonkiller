# Demon Killer M46 | Animal Companions

Tame one weakened wolf from the live creature population by approaching with food. Each attempt has an authoritative skill-based result and cooldown. Successful pets have stable ID, real health, loyalty, follow/stay/guard modes, feeding and release. Pets walk cardinally through the world, defend, can be injured and die, and leave ordinary decaying beast remains. Release turns the pet back into a living wolf.

ANIMALS on the paper doll uses actual server commands. The world does not fabricate pets for the GitHub Pages preview. No new artwork or companion building was added.
