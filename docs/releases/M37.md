# Demon Killer M37 | On-Screen Prison Architect Construction

## Problem fixed
M36 added an editor on a separate page, but left the visible temple Architect button opening the old floating tool window. F8 was only handled outdoors with an active local server and did nothing in the temple or static preview. The building tools weren't consistently visible on the play screen.

## Built
- **Temple:** Clicking Architect or F8 opens a fixed bottom construction dock with Prison Architect-style Foundations, Materials, Rooms, Objects, Staff, Utilities, Deployment, Logistics, Intelligence, Emergencies, Clone, Planning categories and contextual tools directly above. Existing sprite palette is physically moved into the dock and keeps working with original selection handlers; old floating builder is visually retired. Click Walk / return button or F8 to close.
- **Outdoors:** Click Architect in the on-screen game header or F8 to open the exterior world editor as an in-game overlay, without leaving the gameplay document. Exit via F8 or visible close button. Re-entering refreshes the selected current region; closing reloads the map.
- **Exterior editor:** Twelve bottom construction categories (Clone is clearly marked unavailable outdoors) and contextual tool row replace the old six-button direct-toolbar layout. Available building selection, movement, doors, material paint, and inspections are connected to server operations.
- **Static public preview:** Browser-only map drafts support moving whole buildings, replacing/removing doors, ground edits, and export. Draft storage is separate from the character save and does not pretend to update GitHub or the authoritative DK Server.
- **Local DK Server:** New tool scripts/styles are included in the allowlist and existing server-backed edit/validation/backup behavior remains.

## Not part of this build
- No changes to the approved temple/courtyard geometry or Lilith's story anchor.
- No new third-party art or editor screenshot illustrations.
- The physical cutscene of Lilith walking north, transforming, and releasing camera/player control remains a separate feature.
- Staff, deployment and utility category content is limited to existing capabilities; these tabs do not promise unreleased simulation or building systems.

## Test suite
tests/architect-on-screen-m37.cjs checks game entry points, F8 wiring, dock placement, category selection, hosted asset allowlisting, and browser-only layout export.
