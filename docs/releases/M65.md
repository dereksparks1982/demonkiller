# M65 | Siege-to-recovery integration and authoritative world clock

## Scope
One substantial persistent-world build integrating M59–M64 rather than adding unrelated menus or graphics.

### Fix: world clock
- Corrected each minute of a catch-up batch to set `living.minute` **before** executing its world logic.
- Frozen target minute computed before loop so the loop cannot extend as the clock advances.
- Added explicit world-minute drift assertion to catch unsafe future changes.
- Reconciliation and game-world timestamps now use the same authoritative minute as AI, guards, refugees, traffic and scheduler ticks.

### New campaign ledger
- Two saved territory records with phases `peace`, `occupied` and `rebuilding`.
- Persistent start/end timestamps, occupation count, liberation count, complete recoveries and peak displaced population.
- Occupied settlements must be liberated; recovery requires a further 90 safe simulated minutes, living displaced civilians returned, and at least one open real storefront when businesses are present.
- No instant town reconstruction, automatic resurrection, invented stock, or teleportation. Continues the existing business and NPC succession constraints.
- A player can defeat the last monster between world ticks without the ledger making that immediate save invalid. The next eligible tick records liberation.
- New read-only endpoint `GET /api/v1/settlements/campaigns` for server diagnostics.

### Integration correction: medical care
- Guards cannot obtain supplies from absent/deceased vendor NPCs, even if the shop's previous `open` state has not yet refreshed.
- Existing paid consumable, player-service, and physical inventory rules are retained.

### Verification
- Nine registered regression contracts including explicit siege, evacuation, real monster spawn, recovery gate, migration, save validity, deterministic catch-up and staffing integrity.
- Isolated M65 lifecycle and authoritative clock simulations passed.
- Complete Node suite and interactive browser-backed world tests have **not** been executed here. GitHub Actions remains manual-only. No release tag until acceptance.
