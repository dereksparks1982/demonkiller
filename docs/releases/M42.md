# Demon Killer M42 | Creature Ecology and Combat

Seven persistent types: imp, wolf, skeleton, giant spider, wraith, bandit and lesser demon. Each has separate maximum health, damage, aggro, loot and human/beast/demon corpse decomposition. Monster occupations reinforce themselves, roaming threats can appear outside settled safety, and creatures pursue residents and players by cardinal movement. Legacy three-imp invasion tests remain compatible. Combat skill values improve damage; there are no automatic levels from an unverified browser event.

Graphics use deliberately primitive existing in-game pixel shapes. No third-party or unapproved sprites were added.
