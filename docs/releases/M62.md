# M62 | Resource-backed garrison recovery

## Implemented
- Server-authoritative guard/escort care based on injury, physical shop proximity, trained NPC movement and item stock.
- A 30-world-minute treatment interval with last-processed minute, per-patient history and total coins spent/healing received.
- Consumable bandages, meals or herbs are removed from actual registered items, alongside vendor stock mirrors; cash transfers directly from a guard to its shop.
- Healing cannot occur with no money, no stock, closed shop, monster occupation, dead patient, or inaccessible service.
- Player-managed shops requiring the owner to serve are not silently bypassed by NPC logic.
- Existing world/character saves migrate without resets or reallocating existing physical items.
- Read-only server `GET /api/v1/garrison`, strict save ledger validation, eight focused regression tests. Isolated supply accounting/cooldown simulation passed.

## Exclusions
No new artwork, game menus, on-screen buttons, cutscene changes, new save formats, or real-time multiplayer code. Full Node regression and browser testing have not yet been executed. No external RunUO GPL source has been incorporated.
