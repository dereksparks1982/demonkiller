# M70 | DK Architect Whole-World Pixel Painter

**Date:** November 8, 2026  
**Game version:** 0.2.68  
**Server package:** 2.31.14

## Purpose and visual direction

Demon Killer now has the first dedicated **9,216×9,216-tile world painter**, directly accessible in DK Architect without visiting obsolete temple or village scenery. The owner's specific direction is simple **32×32-era coarse pixel art**, visibly matching the existing human and cult NPC sprite style. Look to Ultima Online for topology, not visual polish; **terrain should initially be simpler, not more detailed, than UO**. Never blur, interpolate, use 3D ground models or generate decorative world-map art as a prerequisite.

## Delivered

- The existing DK Architect F8 menu now provides **Logistics → World Pixel Painter**, opening the same full-screen atlas tool within the editor.
- The main menu **Options → Persistent World → Open DK Architect** goes directly to `dk-world-architect-m70.html`, avoiding the old introductory area. It is part of the same browser game and authoritative server, not external Photoshop, GIMP, or a second world editor.
- Crisp 720×720 canvas represents 72×72 Streaming Cells at whole-world zoom. Mouse-wheel zoom moves through 1:128, 1:64, 1:32, 1:16, 1:8, 1:4, 1:2 and 1:1, where one displayed sample is one real tile. RMB-drag pans; LMB-drag selects rectangular material paint. No smoothing.
- Two editing resolutions: **WHOLE CELLS** writes one material per 128×128 Streaming Cell with a sparse persistent record, appropriate for oceans and large biomes. **INDIVIDUAL TILES** uses M69 fine tiles and real signed elevation raise/lower/flatten/smooth operations when zoomed in sufficiently.
- A single cell-fill transaction can paint up to 5,184 Streaming Cells (the entire atlas) with an exact cell undo record. It does not allocate or transmit 84.9 million tile entries. Fine tile overrides always win over whole-cell base materials.
- The authoritative DK Server serializes editing with other world writes, checks expected revision, validates every changed cell, durable-saves the world, and broadcasts edit events. The browser shows the server result and supports undo/redo.
- The editor displays authored water coverage against the owner's approximate 33% ocean target, including fine-material overrides. Unpainted map positions remain intentionally blank, not prebuilt terrain.
- Painting impassable terrain across legacy occupied/fixture-protected M68 preview cells **skips only those cells**, reporting exactly which cells were skipped. The rest of the stroke remains a committed, revisioned operation. The older temple/courtyard are not imported into the new atlas.
- Exports include the sparse cell material records and fine elevation/terrain overrides so actual geography can be inspected without relying on screenshots.

## Server interface

- `GET /api/v1/world/terrain/atlas?x=0&y=0&scale=128&columns=72&rows=72` samples a viewport into simple pixel-block records; allowed scale powers of two from 1 through 128.
- `GET /api/v1/world/terrain/coverage` returns authored land/water counts and a target.
- `POST /api/v1/architect/world-atlas` requires same-origin loopback service and `X-DK-Architect: world-atlas`, JSON action `fill_cells` or `restore_cells` plus exact `expected_revision`.
- The existing `GET /api/v1/world/terrain/export` includes the new `cells` map, with optional cell scope. Existing M69 tile-paint and sector-inspection interfaces remain supported.

## Tests and acceptance limitations

Source JavaScript syntax was checked for all changed modules. Isolated V8 tests of the M69/M70 module interaction passed, including painting 1,728 cell records to achieve 33.3333% sea, viewing full world, restoring cell fills, fine override precedence, corrupt input and stale revisions. New `tests/world-atlas-m70.cjs` covers server persistence, real API access, protected fixtures, save export, and browser contracts. The M69 browser asset-version assertion is compatible with m70.

**NOT yet verified:** complete Node suite on a source checkout, physical browser pointer interaction, persistent server restart under gameplay load, or Firefox smoke test. Do not represent those as passing.

## Not built

M70 is an authoring and sparse storage milestone, **not a complete playable world**. Unpainted atlas positions and newly authored regions are not yet freely traversable by the server's player actor. It does not implement 2.5D height geometry/shading, river hydrology, ocean depth, caves, spawner painting, construction staging, NPC self-founding cities or public always-on server hosting. Old temporary M68 wilderness artwork can still render in the legacy playable prototype while migration continues.
