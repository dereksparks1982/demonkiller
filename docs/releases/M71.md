# M71 | A single flat green world to sculpt

**Date:** November 8, 2026  
**Game:** 0.2.69  
**Server:** 2.31.15

## Why this slice changed

The owner explicitly wants to start with **one enormous flat green plane** and paint terrain personally, rather than begin with the empty/gray checkerboard M70 used for untouched land or with an automatically constructed geography. The world is **9,216 × 9,216 tiles**, 84,934,656 terrain coordinates. The grassland starts at height **0**. Do not generate oceans, rivers, mountains, islands, settlements, or any extra pixel art. The existing NPCs are 32 × 32 pixels; terrain should be simple, blocky and if anything less detailed than Ultima Online.

## Implemented

- `server/world-terrain-editor-m69.cjs` now defines `DEFAULTS={material:'grass',elevation:0}`. New persistent terrain ledgers include a `defaults` object, and `ensure(world)` adds it to older saves without deleting custom cells, terrain heights or building drafts. The schema remains 1 and accepts legacy ledgers missing the field until they are upgraded. Unknown/altered world defaults are rejected by validation.
- Terrain inspection returns `grass` and `0` for every unedited atlas coordinate. Materialized M68 sample region data may still contain old procedural floors, but that is temporary legacy gameplay data, not the new atlas's seed.
- `server/world-atlas-m70.cjs` presents default green grass in the whole-world editor viewport and exports its `defaults` metadata; no 84.9 million grass records are allocated or exported.
- A whole-cell `fill_cells` command with `material:'grass'` removes that cell's prior material fill; it does not create redundant grass records. Undo uses the original cell value, allowing an ocean fill to be restored accurately. Fine grass paint can replace ocean within a cell and exact per-tile elevations persist.
- Fine detail paint and elevation restore omit override fields equal to the inherited base whenever possible; tile-level overrides continue to take precedence over whole-cell fill materials.
- `coverage` now starts at grass=84,934,656, water=0, authored=0. It recalculates water and land from cell fills and fine-material overrides, including elevation-only edited coordinates in authored counts.
- DK Architect's world pixel painter clearly explains the flat green initial state; no new generated scenes or images are introduced.

## Tests and migration

New `tests/grass-plane-m71.cjs` includes ten contracts: four corners and the old sample coordinates, all eight atlas zoom scales, grass/water/unedited counts, ocean-to-grass brush/undo, fine land detail over water, exact elevation persistence, minimal cell and sector records, old save migration, validation against corrupted defaults, original pixel-art UI checks, and a loopback save/restart/export test. Prior M69/M70 tests were updated to expect grass as the atlas base rather than null.

Isolated V8 module interaction checks passed for all core operations and preserved previous authored terrain. **The full Node test suite, a real server restart, and a Firefox browser interaction test were not executed in this remote GitHub editing environment.** Run `npm --prefix server test` on the complete Linux checkout before accepting behavior in-game.

## Important distinction

M71 sets the **replacement atlas's green default** and makes it paintable and server-exportable. The separate M68 playable preview still contains its old generated wilderness floors and unretired story objects; those are NOT the base of the replacement atlas and are deliberately not erased without a dependency migration. The new authored world is not yet continuously walkable for the player. Height-aware movement and river mechanics are future slices.
