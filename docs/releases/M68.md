# M68 | First Walkable World Grid, Old Village Removed

**M67 retained:** Its existing 4096×4096 grid, cell addressing, save metadata, cardinal coordinate arithmetic and building draft work are preserved. M68 supplies a real terrain layer to the first four global 128×128 cells.

## Playable changes
- The Forsaken Temple's old room is preserved, with Lilith's willow and temple exterior retained in a newly simplified woodland. Removed the old courtyard's houses, market, well and village entrance. The old village has no remaining built map geometry and no portal from the playable world.
- Four adjoining wilderness cells, each 128×128 32px overhead tiles, comprise a first 256×256-tile walkable area. Only 65,536 terrain tiles are materialized, not all 16 million planned tiles.
- Coastal ocean, sand shore, meandering river and tributary, inland lake, bog/marsh, forests, highlands, mountains, glaciers, roads and bridges exist as genuine collision-tested tiles.
- Cardinal edge crossing preserves spatial continuity; the temple woodland's north edge joins cell (12,15). The same generated terrain runs in server and browser, with 16×16 streaming sectors.
- Three physical multi-tile worker-camp fixtures: timber, quarry and marsh. No staffed camp production or resource logistics yet.
- The playable game uses original top-down pixel-art rendering with no new isometric world map or extra HUD action buttons.

## Compatibility and limits
Legacy village/courtyard economy and NPC records still exist in hidden disconnected server structures until migrated off M66, but their old buildings and streets have been removed and the old village is inaccessible. M67's world-grid draft structures remain separate and intact. No six major towns or three resource villages have been built in this first slice. The full browser-server integration and automatic Node tests are not claimed as verified.

## Testing
Eight new regression contracts registered. Syntax checks and targeted generator/portal and player-movement simulations passed. M67 grid/root IDs align. No release tag before acceptance.
