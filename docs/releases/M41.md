# Demon Killer M41 | UO-Scale Skills

59 named server-owned skills grouped into combat, magic, gathering, crafting, roguery and social professions, with 100.0 individual cap, 700.0 total cap and UP / LOCKED / DOWN locks. Existing ten-skill character saves are migrated without erasing past progress. The Classic-style paper doll provides categorized, scrollable skills and lock controls.

This is the skill **foundation**, not a claim that all 59 skills already have full activities. Skills must gain from validated world actions, not arbitrary client levels.
