# Demon Killer M47 | Grain, Mill and Flour Production

A first physical economic chain using existing village geography: grain is harvested from the farm patch by the player or a baker, then the baker's existing village workshop grinds 2 grain into 1 grist and sacks 1 grist into 1 flour. The player can run both steps manually at the milling station with tools, inventory checks, world-minute work time and Milling skill gains. NPC work requires the real baker nearby, an open/controlled shop, real item serials and paid wages. The bakery now consumes flour to make bread, and NPC customers continue buying baked goods. Grain/flour can be sold to the existing marketplace/bakery.

The approved village exterior was NOT redrawn. This is the working milling machinery foundation inside the existing bakery workspace. The player can design a separately sized dedicated mill building later using DK Architect; that building is not yet placed or enterable.
