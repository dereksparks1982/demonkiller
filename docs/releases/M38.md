# DK Softworks | Demon Killer M38 | Prison Architect Menu Repair

## Corrective release

M37 was not consistent with the requested Prison Architect user experience. The temple still had its own old editor under the hood; outdoors drew a second generic map in an iframe. The same tools were unavailable across regions, and exterior building movement gave little useful feedback. This release corrects those issues rather than adding yet another competing editor.

### On-screen controls
- A **single shared bottom category strip** is used in temple and outdoor play: Foundations, Materials, Rooms, Objects, Staff, Utilities, Deployment, Logistics, Intelligence, Emergencies, Clone and Planning.
- Clicking a category opens the **Prison Architect-style fly-out command menu directly above that category icon**, while the actual room/world scene stays visible. Available and unavailable tools are distinguished.
- F8 and the existing Architect button toggle the menus in **both** scenes.
- Temple commands continue using the existing original DK Architect 32px sprite palette and functions.
- Outdoors, the editor overlays **the live game canvas**, not an iframe. Right-drag pans the real camera, mouse wheel zooms, and a translucent whole-building preview shows green for valid locations and red for blocked locations. The command menu reports why a location is blocked.

### Movement and persistence
- Shared M38 geometry is used by the server and GitHub Pages' browser drafts to move entire building footprints with their actual wall/floor tile layers, existing doors, stable IDs and original room associations.
- **Underlay preservation:** if a building moves onto garden/grass, its underlying terrain is restored if later moved again. Paths, the temple, gates, other occupied buildings and Lilith's willow anchor cannot be accidentally overwritten.
- Local-server transactions update connected deed/container/vendor records; browser-only edits update map drafts, not characters or an imaginary server. Export produces map JSON for review and integration.
- Outdoors gains basic wall placement/removal, straight walls and room outlines, alongside floors, doors, moving whole buildings, select/inspect, exports and undo/redo for moved properties and doors.
- Menu items that are not supported in a particular region are shown disabled, not represented as finished gameplay systems.

### Scope
No village default geometry is moved by this build. No new artwork. No rebuilt UI artwork from the reference screenshot. Lilith's camera-follow transformation cutscene remains future development, separate from construction UI.
