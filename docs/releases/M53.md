# Demon Killer M53 | Snooping, Pickpocketing and Witnessed Crime

**A real Ultima Online-inspired skill pair**, implemented independently for DK Server.

The **THIEVING** paper-doll panel lists nearby living NPCs. A Snooping action inspects their actual M12 backpack serials without transferring or creating any items, and grants legitimate Snooping practice. The character keeps a validated, ten-world-minute record of the specific item serials they saw. A Pickpocket action is possible only when adjacent to that same living NPC, within the observation window, and targeting a serial still physically held by the victim. Attempts are throttled to one every five world minutes.

The Stealing skill determines a bounded, deterministic success chance. A successful theft transfers exactly one real item: if a stack has one unit the serial moves from the NPC pack to the player pack; if it has multiple units the original stack decreases and a new unique serial appears for exactly one unit. The authoritative player inventory mirror and world entity counts are reconciled. Failed attempts transfer nothing. Both real attempts and successful snoops can train the respective professions. Caravan cargo currently in active transport is protected from pickpocket actions to avoid breaking persistent logistics.

**Witnesses and consequences:** in guarded village districts, a visible successful theft or a detected failure creates a permanent `pickpocket` case in the existing M15 law ledger. A failed attempt alerts the victim, and nearby witnesses report as normal. Lawful fines and criminal heat come from the established system, with guard pursuit and bank fine payment unchanged. Theft in unguarded wilderness is not charged under village law, but all interactions still respect range, character form, NPC life state, inventories, and the authoritative server.

New source: `server/thievery-m53.cjs`. M15 law validation accepts both its original corpse-theft case and the new pickpocket case. New tests: `tests/thievery-m53.cjs`. The public GitHub Pages game remains a static preview; the permanent single-player world runs only while DK Server is actually running. No art, doors, character sprites, temple ritual, or village geometry were changed.
