# M61 | Persistent settlement watch and independent NPC defense

**Scope:** one server-only slice, keeping the browser/GitHub Pages playable game as-is.

- Durable `guard_watch` state per guard and escort NPC, with idempotent migration from older worlds.
- Alarm propagation bounded to nearby sentries and active creature records, no fabricated targets.
- Independent guard pursuit and one melee attack per saved combat interval; no duplicated monster-turn retaliations.
- Respect walls, living NPCs, occupied tiles, player position and actual creature positions.
- Badly wounded guards stop charging; death/succession are handled by the existing NPC life cycle.
- Guard kills call the standard monster death path, preserving corpse decay, loot, bounties and territory-state consequences.
- Strict save validation, limited event history and read-only `GET /api/v1/guard-watch`.
- Seven regression tests registered with the server test runner; isolated guard duty simulation passed. The complete Node suite and browser-run verification are not claimed.
- No changes to opening cutscenes, sprites, MIDI, controls, save identity, or visible action buttons. No third-party RunUO code used.
