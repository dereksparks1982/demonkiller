# Demon Killer M36 | World Construction with DK Architect

**DK Server v2.16.0** • Outdoor editor (first slice)

## Delivered
- Dedicated **local-server-only**, top-down exterior construction workspace at /dk-architect-outdoors-m36.html.
- Prison Architect-style **bottom category toolbar** with buildings, drag-to-move, doors, erase door, materials and inspection. Top bar shows region/revision, undo/redo and map export. Right-button drag pans, mouse wheel zooms, left-button drag selects building footprints or material rectangles.
- **F8 outdoors** enters the editor on the same region. Returning restores the single-player client; no play-screen editor buttons are introduced.
- Authoritative move operations reposition all building wall/floor layers, exterior doorway, Stream Cell rectangle and the same object's stable ID. The existing save's furniture, business inventories, house ownership and deed IDs remain intact.
- Door replacement/removal updates actual perimeter collisions. A doorless house still owns its goods but cannot be interacted with until it has a valid door again.
- NPC-shop vendor containers and home storage coordinates move with their source buildings.
- Ground/material brush has a bounded rectangle edit. Original paths and temple are left untouched unless explicitly edited through the brush.
- Every edit is revision-checked, serialized and written via DK Server's durable atomic backup strategy. Error responses distinguish stale edits, invalid geometry and server/storage failures.
- **EXPORT JSON** yields only the selected map data and stable object IDs. Send it to the maintainer to review and integrate into the authored map defaults; the editor does not write to GitHub or overwrite the world save from browser-provided data.
- Original courtyard and village layouts are not moved as part of this release. Lilith's cinematic remains a separate follow-up task. The central willow anchor is protected, not replaced by generic scenery.

## Limitations and next steps
- Interior drafts remain **unpublished** and cannot yet be entered. This release focuses on outdoor authoring.
- Moving authored houses/shopping buildings and moving/replacing doors work; newly creating arbitrary buildings, multi-door buildings and exterior wall resizing remain later work.
- The public GitHub Pages preview is read-only; do not pretend that it can persist world/server changes.
- On-screen undo/redo is available for building and doorway operations in the active editor session. Ground brush is already committed; it currently has no undo action.
- Player movement, story triggers, house access, NPC routes, and scene art remain server-controlled. Do not import old UO/third-party artwork.
