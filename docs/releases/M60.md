# M60 | Classic Ultima Online Controls and Persistent Combat Intelligence

## Control review
The documented Ultima Online classic bindings are **Tab/Alt+C War/Peace**, **Alt+P paper doll**, **Alt+I backpack** (Alt+D alias from older references), **Alt+K skills**, **Alt+J journal**, **Alt+R radar**, **Alt+S status**, **Alt+B spellbook**, **Alt+O options**, **Alt+X leave**, and **Alt+Enter fullscreen**. The classic mouse contract is hold right to travel, left to inspect, double left to use or attack in War Mode. Full speech macro, chat, notoriety and drag/drop parity require their own authoritative systems and are not claimed.

## Implemented
- Saved War Mode per character, server-validated toggle with exact accepted action shape. Old characters migrate to Peace without resetting saves.
- Temple and outdoor keyboard adapters, reference window, non-interactive war badge, on-demand skill/status/journal/radar/spells/options views; keyboard-only so the play screen remains uncluttered.
- Existing P/I/C/B/F8 controls still work. Ctrl/Meta shortcuts, inputs and Architect interactions are not hijacked. Ritual and Lilith transitions block stance changes.
- Peace Mode creature double-click examines, War Mode double-click attacks via existing authoritative combat. T nearest-hostile and L last-target macros use existing combat actions.
- Server-owned monster memory and finite pursuit, search, retreat and return states. Saved creature-home and last-seen metadata, legacy migration, basic collision-safe repositioning and obstacle-sensitive sight.
- Read-only monster-AI endpoint.
- M60 regression contracts for both branches of War toggling, key routing, persistence/migration, creature AI and HTTP integration. No additional third-party art, music or GPL code.

## Testing and acceptance
Selected module syntax and isolated AI transitions were checked during authoring. The full Node suite and interactive Firefox playtest are **not claimed complete**. No GitHub Actions workflow was started and no release tag is made before owner acceptance.
