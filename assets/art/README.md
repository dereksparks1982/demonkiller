# Demon Killer Art Library

Game-ready art assets for Demon Killer and DK Architect.

- `dkarchitect/ui/`: original medieval pixel UI artwork for the Architect toolbar.
- `dkarchitect/imported/`: the 0x72 Original Dungeon Tileset v5, 0x72 Dungeon Tileset II v1.7, Pixel_Poem 2D Pixel Dungeon Asset Pack v2.0 and Pixel_Poem Enemy Animations Set, stored as tightly packed in-game atlases with original frame metadata.
- `temple/ritual/`, `temple/floors/`, `temple/doors/`, `temple/furniture/`: existing game objects, floors and ritual props.
- `characters/`, `crystals/`, `shared/`: Demon Killer original sprites.

All previously generated or cropped Demon Killer wall sheets were rejected and removed from active `main`. No art in `dkarchitect/walls/` or `temple/walls/` is used anymore. Historical source art remains recoverable from Git history.

Creator credits and source links: `docs/third-party-dungeon-art.md`.
