# Demon Killer

Demon Killer is a single-player, top-down Gothic fantasy RPG by DK Softworks, inspired by Ultima Online.

Explore the temple, courtyard, and village with continuous mouse movement, a paper doll (P), and a backpack (I). The local DK Server handles persistent world saves, NPC activity, crafting, trading, and world changes. The online version is a browser preview.

[Open Demon Killer](https://dereksparks1982.github.io/demonkiller/)
