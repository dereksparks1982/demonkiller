# Demon Killer

A single-player Gothic fantasy game by DK Softworks, with original top-down pixel art, Streaming Cells, and a persistent-world server in development.

[Play Demon Killer](https://dereksparks1982.github.io/demonkiller/)

## DK Architect

Click **ARCHITECT** or press **F8**, inside the Forsaken Temple or outside. The **same Prison Architect-style category menus and approved asset catalog** open above the bottom toolbar and edit the live game map. Choose a tool, then click or drag on the grid. The exterior Foundations menu includes **MOVE WHOLE BUILDING**; doors, wall and floor tools, placed objects, rotation, copy/paste, undo/redo and JSON export are also available. The temple retains its approved scene and story controls.

On GitHub Pages, layout edits save **in your browser**, separately from your character. Use **Logistics → Export Map JSON** to send your edited layout back for review and integration. GitHub Pages itself does not host the persistent DK Server.

The GitHub Actions six-shard regression workflow is **manual-only** to conserve Actions minutes. The necessary GitHub Pages publication continues on pushes.
