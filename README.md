# Demon Killer

Demon Killer is a single-player, top-down Gothic fantasy RPG by DK Softworks, inspired by Ultima Online.

Explore the temple, courtyard, and village, interact with characters, and fight monsters. The local DK Server adds persistent world saves, NPC activity, crafting, trading, and a changing world. The online link is a browser preview; the persistent server runs locally.

[Open Demon Killer](https://dereksparks1982.github.io/demonkiller/)
