# Demon Killer

**Demon Killer** is an engine-free, top-down Gothic fantasy adventure inspired by the open-ended worlds and player freedom of classic Ultima Online.

In the Forsaken Temple, the player survives a dark ritual as a wandering spirit and can choose whether to return to their body or continue as a ghost. The game currently includes character slots, cult investigation features, and **DK Architect**, an in-game construction tool for placing walls, floors, furnishings, and original pixel-art objects. Main menu Options include a music toggle and an adjustable amplified volume control.
