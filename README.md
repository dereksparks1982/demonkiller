# Demon Killer

**Demon Killer** is a top-down Gothic fantasy adventure by **DK Softworks**, built with original pixel art. Explore the Forsaken Temple as a ghost, investigate its objects and mysteries, and choose whether to return to life through the soul crystal.

The game includes character save slots and **DK Architect**, an in-game tool for building and editing the temple.
