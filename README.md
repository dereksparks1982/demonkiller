# Demon Killer

**Demon Killer** is an engine-free, top-down Gothic fantasy adventure by **DK Softworks**, built with original pixel art. In the Forsaken Temple opening, the cult sacrifices the bound player, the Devil confronts the emerging ghost, and Lilith leaves a glowing soul crystal after praying at the altar. The player can deliberately resurrect or remain a ghost.

The game includes character save slots and **DK Architect**, an in-game tool for building and editing the temple.
